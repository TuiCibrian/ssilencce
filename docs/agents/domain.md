# Domain docs

Single-context repo: domain knowledge lives in Architecture Decision Records (ADRs) under `docs/architecture/` plus this `AGENTS.md`. No root `CONTEXT.md`.

## Layout

- `docs/architecture/ADR-*.md` - 65 ADRs, ADR-001 through ADR-065 (see directory); the numbered, dated record of architectural decisions
- `AGENTS.md` — repo conventions and rules for agents
- `docs/CODE_MAP.md` — per-file code map

## Consumer rules

- Before changing architecture, read the relevant ADR(s) and cite them by number when a decision constrains a change
- Key stack decisions: Koin (ADR-006), Ktor (ADR-020), Navigation 2.9.8 (ADR-027), hybrid View/Compose (ADR-026), legacy now-playing styles (ADR-028), dynamic color/theming (ADR-029), pre-Aurora UI restoration (ADR-035)
- ADR-033 and ADR-034 are superseded by ADR-035. The `apply-aurora-glass-*` proposals are historical records of a reverted implementation. ADR-036 authorizes the new optional native reference implementation tracked as `implement-native-aurora-reference`; see `docs/AURORA_REFERENCE.md` for capability mapping. ADR-037 refines the Aurora chrome (drawer-led navigation, retired category strip, floating header actions) under the `refine-aurora-chrome` change. ADR-038 keys the persisted playback queue by position (`order`), allowing repeated songs to survive restarts. ADR-039 refuses release packaging without configured release signing and bans the silent debug-keystore fallback (explicit local opt-in only). ADR-040 adds append-only play events for period statistics; ADR-041 implements named queues and queue-local search (superseding the ADR-036 availability decision); ADR-042 defines per-track resume, audio-focus modes, the Quick Settings tile and bounded session recovery; ADR-043 defines opt-in scheduled backups; ADR-044 covers settings/list search, export formats and entity shortcuts; ADR-046 supersedes the outgoing-save ordering in ADR-041 with an await-before-binding, abort-on-failure switch; ADR-047 makes Settings restore a live typed SharedPreferences import so the cached singleton cannot write back stale values; ADR-048 adds selective favorites, play-count, named-queue and per-file-position backup/restore types; ADR-049 adds offline EBU R128 ReplayGain calculation, complete-album grouping, presence-aware gain and verified format-aware tag writes. ADR-050 adds per-widget appearance settings, transparency floors, shared empty states and a Compose configure/reconfigure activity. ADR-051 defines batch tag-write integrity; its fully fail-closed design is only partially implemented (see below).
- ADR-052 adds the dual-player crossfade, keeping queue/session ownership on the main player and treating a crossfade commit as an automatic transition. ADR-053 adds flavor-scoped Chromecast (media3 `CastPlayer` facade + LAN HTTP server; github/playstore only, fdroid GMS-free). ADR-054 renders screencast output as an `android.app.Presentation` on external presentation displays while audio stays in the local ExoPlayer/DSP pipeline (no mirroring). ADR-055 makes `PlaybackVolumeController` the single volume writer and adds the gapless audio-sink gate. ADR-056 adds the persisted three-state shuffle (off / shuffle / randomize), configurable button cycle and prefix-preserving/randomize order policies. ADR-057 adds the external-audio mini player plus connect/resume/mute policies. ADR-058 adds service-owned in-track A-B repeat and per-song speed/pitch in Room v9. ADR-059 adds AIFF/DSD extractors and opt-in supplementary indexing while keeping APE/WMA unplayable. ADR-060 filters ghost folders in the shared media query layer. ADR-061 adds the first-run setup wizard and process-scoped media-mount rescan. ADR-062 defines folder create/rename/move/copy across scoped storage. ADR-063 adds the post-inflation entity menu customization filter. ADR-064 adds the configurable Media3 notification provider. ADR-065 adds opt-in RemoteViews notification styles while the system Media3 notification remains the default.
- ADR-051 is partially implemented by `openspec/changes/tag-editor-finish` (cache-dir session journal, current-file rollback for hard failures, session undo); its fail-closed hash/sidecar validation and process-death recovery are not implemented.
- Never propose something contradicting a settled ADR without a new ADR superseding it
- ADR-045 orders immutable queue snapshots across pause/service teardown and restore barriers; it also defines same-UID app commands and request-bound, restorable audio-focus consent. ADR-047 partially supersedes only its Settings-restore SharedPreferences coherence consequence.
